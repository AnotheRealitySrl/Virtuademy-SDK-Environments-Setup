# Virtuademy-SDK-Environments-Setup

## How to install

### Add this repository as a submodule

Copy this link: "https://github.com/AnotheRealitySrl/Virtuademy-SDK-Environments-Setup.git".

In your Git client, add a new submodule.
- Use the copied link as the source.
- As destination path, write "Packages\Virtuademy-SDK-Environments-Setup".
